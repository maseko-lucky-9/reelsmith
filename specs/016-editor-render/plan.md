# Implementation Plan: The clip editor's edits render

**Spec**: [spec.md](spec.md) | **Decision**: [ADR-014](../../docs/decisions/014-timeline-schema-v2.md)

- **Words.** `app/services/clip_words.py` owns the sidecar (`clip_words_path`, `read_clip_words`, `write_clip_words`, `clear_clip_words`, `backfill_clip_words`) and `default_timeline`. `_process_chapter` writes it with `segment_discovery.write_words_sidecar` on every render. `app/routers/clip_edits.py` `_clip_words` reads it or backfills through `transcribe_words_async`, counted as work on the job (`orchestrator.claim_work`).
- **Schema v2.** `app/services/timeline_render_service.py` parses both versions in one `_parse`: `validate_timeline` (used by `PUT`, lenient about the v1 placeholder) and `build_render_plan` (strict) share it. `_segments` checks order, overlap, length and the source range; `resolve_audio_src` resolves voice-over names. `RenderPlan` gains `segments`, `audio`, `caption_style`, `mute_source`, `source_path`. See ADR-014.
- **Render.** `app/services/render_service.py`: `plan_segments` (plan to source windows; a v1 `src` must be the job's own source), `plan_caption_entries`, `write_overlay_images`, `segment_crop_track`, `build_plan_argv` (one graph: split, trim/atrim per segment, concat, captions, overlays, voice-over `adelay` plus `amix`, ducking) and `_render_plan`; `render_clip` takes `plan=`. Captions go through `caption_track` and `subtitle_image_service.create_subtitle_image` with `caption_style_for_preset`; overlays through `create_text_overlay_image`. ffmpeg runs only through `ffmpeg_tools.run` (constitution III, ADR-004).
- **Re-render.** `_rerender_clip` in `app/workers/orchestrator.py` loads the clip's edit (`store.get_clip_edit`), plans it in a worker thread (`_plan_saved_edit`, which also re-bases a v1 edit onto the source) and passes `edit=` to `_process_chapter`, which renders the plan's window with the plan's words as the captions and rewrites the sidecar. The hidden-partial swap and the cancel path are spec 013's.
- **Voice-over.** `app/services/voiceover_service.py` adds `clean_text`, `voice_model_path`, `piper_command`, `resolve_provider`, `reserve_output_path`, `wav_duration` and `synthesize_voiceover` beside the older `synthesize`; `app/routers/voiceover.py` is the route. New settings `voiceover_provider`, `voiceover_model_dir`, `voiceover_voice` (documented in `.env.example`, which a drift test requires). `piper-tts==1.8.0` and its `pathvalidate` dependency join `requirements.txt`. `scripts/fetch_piper_voice.py` downloads `<voice>.onnx` and `.onnx.json` from `rhasspy/piper-voices` on Hugging Face to a `.part` file and renames it when complete.
- **Hook fix.** `app/routers/ai_hook.py` `_transcript_text` accepts a string, a segment list, and the `text`/`segments` dict shapes.
- **Editor.** `web/src/lib/timelineEdit.ts` (pure helpers: v1 to v2 upgrade, split, trim, caption text and style, add and remove items), `web/src/components/editor/EditorToolPanels.tsx` (Captions, Text, Voice-over, Trim), `MultiTrackTimeline.tsx`, `useTimelineEditor.ts`, `web/src/routes/clips.$clipId.edit.tsx` (transcript edits, Re-render saving first), `CaptionTemplatePicker.tsx` (no badge).
- **No migration.** `clip_edits.timeline` is a JSON column; `schema_version` and the new keys live inside it.
- **Verification.** `ruff check app tests scripts`, default `pytest`, `cd web && pnpm test && pnpm build`; every new test mutation-checked; no DB-integration test against the shared compose Postgres. Then the three open checks (T133-T135).
